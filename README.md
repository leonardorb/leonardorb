# Leonardo (Leo) Barbosa

**Software architect.** Twenty years building scalable, reliable systems end to
end: infrastructure, databases, APIs, and the interfaces on top of them.

I have architected production systems on AWS, GCP, and Azure, written backends in
Node.js and Ruby on Rails, and built frontends in React, React Native, and Vue.

## Architecture and AI

I design and build agentic systems: MCP servers, subagents, hooks, tool
orchestration, and multi-agent workflows.

My work spans Anthropic, OpenAI, Google, and open-weight models, driven through
Claude Code, Codex, Cursor, and Copilot. I build integrations to be
provider-agnostic and to meet production constraints: cost ceilings, latency
budgets, and compliance boundaries.
